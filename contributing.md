## 🔧 Setup Walkthrough

### Step 1 — Create the Painter
Subclass `CustomPainter` and override `paint`.

### Step 2 — Draw Shapes
Start with rectangles and circles.

### Step 3 — Build Paths
Move to `Path` and `quadraticBezierTo`.

### Step 4 — Apply Shaders
Add `LinearGradient` and `RadialGradient`.

### Step 5 — Animate
Drive it with `AnimationController`.

### Step 6 — Profile
Wrap with `RepaintBoundary` and measure.

## 💡 Best Tips

- ✅ Prefer vectors over bitmaps
- ✅ Reuse `Paint` objects
- ✅ Skip work when invisible
- ✅ Use `shouldRepaint` wisely
- ✅ Keep animations at 60 FPS

## 🔧 Troubleshooting

| **Problem** | **Solution** |
|--------------|---------------|
| **Blurry output** | Match device pixel ratio |
| **Laggy animation** | Reduce path complexity |
| **Hit-test fails** | Use path.contains |
| **Shader not applied** | Check paint order |
| **Full-screen repaint** | Add RepaintBoundary |
| **Crash on resize** | Handle size changes |
